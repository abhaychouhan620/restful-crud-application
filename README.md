# RESTful CRUD Application 🚀

A simple RESTful CRUD application built using **Node.js, Express.js, EJS, and JavaScript**.

This project demonstrates how to create and handle REST API routes for performing CRUD operations on resources.

## 📌 Features

- Create a new resource
- Read/display all resources
- Read a specific resource
- Update an existing resource
- Delete a resource
- RESTful routing
- HTTP methods: GET, POST, PATCH, DELETE
- EJS templates for rendering pages
- Express middleware for handling requests
- Unique IDs using UUID

## 🛠️ Technologies Used

- **Node.js**
- **Express.js**
- **EJS**
- **JavaScript**
- **UUID**
- **Method-Override**
- **HTML & CSS**
